## اجرای روی GitHub Pages

### روش ۱: سریع (پیشنهادی)

1. یک ریپازیتوری جدید در گیت‌هاب بساز (مثلاً `lumera`)
2. فایل‌های داخل این پوشه را آپلود کن (`index.html` و `README.md`)
3. برو به **Settings → Pages**
4. Source را روی **Deploy from a branch** بگذار
5. Branch را `main` و پوشه را `/ (root)` انتخاب کن
6. ذخیره کن و چند دقیقه صبر کن

آدرس سایتت می‌شود:
`https://YOUR_USERNAME.github.io/lumera/`

### روش ۲: با Git

```bash
git clone https://github.com/YOUR_USERNAME/lumera.git
cd lumera
# فایل‌ها را کپی کن
git add .
git commit -m "🚀 Launch Lumera"
git push
```

سپس Pages را مثل بالا فعال کن.

## نکات

- این نسخه یک **دموی کامل فرانت‌اند** است.
- داده‌ها در `localStorage` مرورگر ذخیره می‌شوند.
- برای نسخه واقعی نیاز به بک‌اند (مثلاً Supabase یا Firebase) دارید.
- همه قابلیت‌های اصلی شبیه‌سازی شده‌اند و قابل کلیک و تست هستند.
